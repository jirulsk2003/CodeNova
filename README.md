# 📌 About CodeNova

**CodeNova** is my personal developer portfolio website.

The project is designed to present my professional profile, technical skills, projects, resume, and development journey through a clean and responsive web interface.

The main purpose of CodeNova is to create a single online platform where recruiters, companies, developers, and visitors can learn more about my technical background and work.

The project was developed as a personal portfolio project while improving my practical web development skills.

---

# 🎯 Project Purpose

The main purpose of CodeNova is to build a professional online identity as a software developer.

The website provides a central place to showcase:

- 👨‍💻 Developer profile
- 🛠️ Technical skills
- 🚀 Personal projects
- 📄 Resume
- 🌐 Developer information
- 💻 Web development experience
- 📚 Learning journey
